# 🏠 InmoLead IA

Proyecto de automatización inmobiliaria desarrollado con **n8n, Gemini, Notion, Telegram y Slack**.

El sistema permite:

- 💬 Recibir consultas por Telegram.
- 🧠 Analizar intención con IA y mantener memoria conversacional.
- 🏡 Recomendar propiedades.
- 📅 Gestionar solicitudes, confirmaciones, rechazos y cancelaciones de visitas.
- 👤 Incorporar aprobación humana mediante HITL.
- 🚨 Registrar y gestionar errores.
- 📊 Monitorear el sistema mediante un Dashboard Ejecutivo en Notion.
